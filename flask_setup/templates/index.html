Spotify Database Dashboard

A Flask + MySQL dashboard for exploring a Spotify-inspired music database.

Welcome

This dashboard allows you to explore genres, artists, albums, tracks, audio features, users, and statistics using the navigation bar above.

All data is stored in a MySQL database and presented using Flask templates. The project is designed for learning, experimentation, and demonstration.

How to use this application

  • Use the navigation bar to move between different database sections.
  • The Users page allows viewing and managing user records.
  • The Statistics page provides insights such as popular genres and totals.
  • Login is required to access restricted sections.
